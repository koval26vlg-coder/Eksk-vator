# HANDOFF — передача контекста между сессиями

Краткие решения и **«не делать X»**, чтобы не повторять отклонённые шаги. Файл **в git**: не пишите сюда секреты, ключи API и значения из приватного `.env` / `secrets.env`.

Полный чеклист источников контекста (git, логи, скрипт, транскрипты, GitHub) — **`AGENTS.md`**, раздел **«5. Контекст между сессиями»**.

## Как вести записи

- Добавляйте **новые записи сверху** (сразу под этой секцией «Записи»).
- Одна мысль — коротко: дата, что решили, почему; или явно: «**Не делаем** … — потому что …».
- Ссылки: `Issue #N`, URL GitHub, или в коммите `Refs #N` / `Fixes #N`.
